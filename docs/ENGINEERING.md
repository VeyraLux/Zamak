# Zamak 工程指标

Zamak 跟踪产物体积、运行性能、构建速度和内存安全：

| 维度 | 当前策略 | 验证方式 |
| --- | --- | --- |
| 体积 | 生成独立原生可执行文件；预览包只携带 `zam.exe`、文档和示例 | `tools/package-preview.ps1` 记录 ZIP/SHA-256；`tools/measure-build.ps1` 记录可执行文件与缓存字节数 |
| 运行性能 | 生成 C，保留溢出/除零/越界语义；区间分析、有限循环分析和调用专用版本只在可证明时消除检查 | `docs/PERFORMANCE.md` 的同输入、多次交错基准 |
| 构建速度 | `check` 不调用 C；对象/链接按内容缓存；叶子修改只重新构建受影响模块 | `zam/tests/build.rs` 的 HIT/MISS 断言；`tools/measure-build.ps1` 的冷/热/增量重复测量 |
| 内存安全 | 所有权/借用检查、整数安全、数组边界检查；证明失败时回退到运行时检查 | `zam/tests/ownership.rs`、`values.rs`、`ranges.rs`、`specializations.rs` |

## AI 反馈指标

离线评测位于 `bench/ai/`，不调用网络或模型，使用固定候选和固定修复补丁，避免把模型差异误当作编译器能力：

- 首次检查通过率：候选不修改时 `check --json` 是否成功；构建与执行结果单独记录；
- 修复轮数：当前评测每个错误案例只应用一轮确定性补丁，记录检查、构建和输出是否全部通过；
- 诊断匹配率：首轮诊断的 `code` 是否等于案例期望值，覆盖词法、类型、所有权、借用、越界与算术、返回值分类；
- 反馈延迟：保留每次 `check --json` 样本，报告首次耗时和后续样本中位数。首次运行不代表操作系统冷缓存；
- 构建与体积：使用独立 Zamak 缓存记录首次构建、缓存命中构建耗时和可执行文件字节数；多模块增量场景见下节。

运行结果写入被忽略的 `results/ai-bench-*`。这些结果衡量工具链的检查与修复过程，不代表任意模型的生成质量。

本机最近一次运行（10 个案例、`-LatencyRepeats 3`）：诊断 code 匹配 10/10、可修复案例的执行输出核对 9/9、`check --json` 中位约 33 ms、首次构建约 360 ms、缓存命中构建约 165 ms。案例数与耗时都随候选集变化，不能当成编译器质量分数。

## 构建与体积测量

`tools/measure-build.ps1` 生成固定形状的多模块工程（默认 6 个模块加 `main`），每轮使用全新缓存目录，重复测量并取中位数：

```powershell
pwsh -File tools/measure-build.ps1 -ZamPath .\zam\target\debug\zam.exe -Modules 6 -Repetitions 3
```

脚本自带断言：冷构建应全部 `OBJECT MISS`，热构建应全部 `OBJECT HIT`，实现编辑只应重编被改模块，导出接口编辑应重编该模块与其调用方。断言失败即报错，避免把缓存失效错误记录成性能数据。正式样本前默认先在一个丢弃的副本上跑一轮冷/热构建（`-Warmup 0` 可关闭），把 C 工具链与头文件读入系统文件缓存，否则首次读取编译器的开销会混进样本。结果写入被忽略的 `results/build-measure-*`，同时记录可执行文件与缓存目录字节数。

本机两次预热后的测量（Windows 10、MSVC、debug 编译器、6 模块、3 次中位数）：冷构建 544/622 ms、热构建 144/170 ms、实现编辑 325/345 ms、接口编辑 355/412 ms、`check` 31/35 ms；可执行文件与缓存目录字节数两次完全一致，分别为 142,848 与 448,804 字节。未预热时同机冷构建可到 870 ms，字节数不变。时间在同一台机器上也有约 10%–15% 的轮次波动，绝对值只适合同机对比；字节数是确定值。脚本不测量峰值内存（峰值内存与二进制体积见 [PERFORMANCE.md](PERFORMANCE.md) 的独立表），也不代表其他机器或 release 编译器。

## 约束

验证性能改动时，遵循以下要求：

1. 相同输入、算法、校验和与正确性断言；
2. 不通过删除安全检查、改变错误语义或削弱竞争者基准获得优势；
3. 同时运行完整测试、`cargo fmt --check`、严格 Clippy；
4. 报告冷构建、热构建、增量修改和可执行文件/预览包体积，不能只报告最快一次。
