# 附录 C：关键字与运算符

## 关键字

下面这些词是保留字，不能用作名字：

| 关键字 | 用途 |
| --- | --- |
| `fn` | 声明函数或匿名函数。 |
| `let`、`mut` | 绑定名字；使它可变。 |
| `const` | 声明编译时常量。 |
| `struct`、`enum` | 声明类型。 |
| `pub` | 让声明对其他模块可见。 |
| `use` | 导入模块。 |
| `extern` | 声明 C 函数。 |
| `if`、`elif`、`else` | 分支。 |
| `while`、`for`、`in`、`break`、`continue` | 循环。 |
| `match` | 按模式选择。 |
| `return` | 离开函数。 |
| `fail`、`catch` | 返回错误；处理错误。 |
| `assert` | 检查条件。 |
| `and`、`or`、`not` | 逻辑运算。 |
| `pass` | 空代码块。 |
| `self` | 调用方法的那个值。 |
| `true`、`false`（也可写 `True`、`False`） | 布尔值。 |

## 运算符优先级

从结合最松到最紧排列。同一行的运算符从左往右结合，只有 `**` 从右往左结合。

| 运算符 | 含义 |
| --- | --- |
| `a if c else b` | 条件表达式 |
| `or` | 逻辑或 |
| `and` | 逻辑与 |
| `not` | 逻辑非 |
| `==`、`!=`、`<`、`<=`、`>`、`>=`、`in`、`not in` | 比较与成员判断 |
| `\|` | 按位或 |
| `^` | 按位异或 |
| `&` | 按位与 |
| `<<`、`>>` | 移位 |
| `+`、`-` | 加减 |
| `*`、`/`、`//`、`%` | 乘除 |
| `-x`、`~x` | 取负与按位取反 |
| `**` | 乘方 |
| `x[i]`、`x[a:b]`、`x.f`、`f(...)`、`x?` | 下标、切片、字段、调用、传递错误 |

这个顺序与 Python 相同。例如 `-2 ** 2` 是 `-(2 ** 2)`，`x & 1 == 1` 是 `(x & 1) == 1`：

```zamak
fn main():
    println(-2 ** 2)
    println(2 ** 3 ** 2)
    println(1 + 2 * 3)
    println(5 & 1 == 1)
    println(not 1 > 2 and 3 > 2)
```

## 赋值运算符

`=` 是赋值。复合运算符 `+=`、`-=`、`*=`、`/=`、`//=`、`%=`、`&=`、`|=`、`^=`、`<<=` 和 `>>=` 就地更新变量、字段或元素。赋值是语句而不是表达式，所以不能出现在条件里。

## 其他符号

| 符号 | 用途 |
| --- | --- |
| `:` | 结束开启代码块的行；分隔名字和类型；分隔结构体字段和它的值。 |
| `->` | 引出函数的结果类型。 |
| `!` | 在类型里分隔结果和错误：`i64!string`。 |
| `&`、`&mut` | 在类型或实参里表示只读借用或可变借用。 |
| `#` | 开始注释。 |
| `@wrapping` | 在紧随其后的函数里关闭溢出检查。 |
| `..` | `for i in a..b` 里的区间。 |
| `\|` | 在 `match` 模式里分隔几种可能。 |
| `_` | 在模式或拆包里忽略一个值。 |
